## 🚀 Deployment

See `CLOUDFLARE_DEPLOY.md` for detailed deployment instructions.

**Quick Deploy:**
1. Go to https://dash.cloudflare.com
2. Workers & Pages → Create → Upload assets
3. Drag and drop this folder
4. Deploy!

See `WEB3FORMS_SETUP.md` for instructions to activate the contact form.

2. Replace `YOUR_WEB3FORMS_ACCESS_KEY` in index.html (line 608)
3. Done!
